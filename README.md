# Student Performance Prediction System

## About the Project
This is a Machine Learning project that predicts
students' exam scores based on their academic
performance and study-related factors.

## Dataset

The dataset used in this project contains 10,000 student records and 8 columns.

### Dataset Features
- Study Hours
- Attendance
- Sleep Hours
- Internet Usage
- Assignments Completed
- Previous Score
- Exam Score
- Placement Status

### Dataset Download
